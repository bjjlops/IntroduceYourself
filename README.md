# Introduce Yourself

## App Description

Introduce Yourself collects a student's first name, last name, school, academic year, number of pets, and pet preference. It then presents the information in a personalized introduction alert.

## Required Features

- [x] App displays an image of a school's logo
- [x] App has three text fields for first, last, and school names
- [x] App has a segmented control that changes the student's academic year
- [x] The number-of-pets label is increased or decreased by a stepper
- [x] A switch records whether the user wants more pets
- [x] The Introduce Yourself button shows an alert with the introduction and a dismiss button
